# MeshTorch

MeshTorch enables high-performance, distributed processing on a unified system platform, leveraging GPU-accelerated computations and dynamic-scaling capabilities.

With MeshTorch, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/MeshTorch.git`
2. `cd MeshTorch`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure MeshTorch, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
